HTML Template

Ini adalah template SVG sprites HTML, svg sprites adala kumpulan icon dalam satu file svg dan bisa digunakan satu persatu hanya dengan memanggil nama id nya.

  • Copy dan paste code dibawah di notepad kemudian save dengan format .svg
  • Kemudian include-kan file svg tersebut ke dalam project
  • Pastikan setiap sprites menggunakan id yang berbeda

Untuk menggunakan icon di HTML, gunakan code ini dan masukkan id icon yang akan dipakai. Tambahkan sedikit CSS agar warna icon mengikuti warna teks di sekitarnya. Untuk mempermudah mengatur ukuran icon, bisa menambahkan CSS untuk ukuran.

CSS Template

Ini adalah template SVG sprites versi CSS, versi ini bisa dipakai pada atribut pseudo ::before dan ::after dalam css. Gunakan pada div atau element lain dengan position: relative; sebagai container.

  • Buat file CSS dan copy susunan berikut lalu save
  • Kemudian include-kan file CSS tersebut ke dalam project
  • Pastikan setiap sprites menggunakan nama variable yang berbeda
  • Path yang dipakai disini sama dengan yang ada di versi HTML, jadi tinggal di copy saja dan taruh di dalam d

Untuk menggunakan icon di CSS, gunakan code ini dan masukkan nama variable icon yang akan dipakai. Tambahkan CSS untuk pseudo seperti dibawah.
