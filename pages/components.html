Buttons

Kumpulan tombol klasik dengan style tombol standar, outline dan link. terdapat juga pilihan semantik warna untuk kebutuhan website.

  • Untuk menggunakan style outline, cukup tambahkan -outline di akhir class warna.
  • Style outline tidak tersedia untuk cr-link, karena tombol link secara default tanpa border.

Style tombol diatas ditujukan untuk tag <button>, namun bisa juga dipakai untuk tag <a> ataupun <input>

href

Button Size

Suka ukuran tombol yang lebih kecil? atau yang lebih besar? Cukup tambahkan class cr-sm atau cr-lg untuk merubah ukuran tombol.

button disabled

Ubah tombol menjadi seperti inactive dengan menambahkan atribut disabled ke dalam tombol. Tombol yang memiliki atribut disabled tidak bisa di klik, hover atau tindakan lainnya.

button icon

Style tombol ini dibuat agar tetap konsisten saat di sisipkan icon. Cukup masukkan font icon sebelum atau sesudah teks tombol.

Jika ingin tombol dengan icon saja, tambahkan class cr-icon untuk membuat tombol ikon dengan ukuran 1:1.

Checkbox & Radio

Komponen checkbox dan radio dibungkus dengan .cr-check-group dan cr-radio-group dengan default display: block;

  • Untuk penggunaan lebih dari 1 radio dalam 1 group, wajib menambahkan atribut name dengan text yang unik untuk membedakan setiap group radio.
  • Tiap group radio harus memiliki name yang berbeda agar tidak saling bersinggungan.

Checkbox & Radio inline

Untuk membuat menjadi inline atau dalam 1 garis lurus, tambahkan class .inline setelah class .cr-check-group dan cr-radio-group.

Checkbox & Radio Size

Checkbox dan radio juga memiliki ukuran small dan large, cukup tambahkan class cr-sm atau cr-lg untuk merubah ukuran label dan input.

Checkbox & Radio disabled

Nonaktifkan checkbox dan radio dengan menambahkan atribut disabled. Checkbox dan radio yang memiliki atribut disabled tidak bisa di klik, hover atau tindakan lainnya.

Dropdown

Ada 2 jenis dropdown, dropdown standar dan dropdown icon. Untuk menggunakan dropdown icon, cukup tambahkan class .cr-icon setelah class .cr-drop-toggle untuk membuat tombol dropdown menjadi kotak 1:1 dan menghilangkan tanda icon panah.

  • Untuk penggunaan dropdown lebih dari 1, pastikan membuat ID berbeda untuk tiap dropdown. ID ini bertujuan agar dropdown dapat bekerja secara mandiri dan tidak saling mengganggu.
  • Tag <a> di dalam .cr-drop-menu bisa diganti dengan <button> dan pastikan tetap menggunakan class .cr-drop-item.

Switch

Ada 2 pilihan switch, switch tanpa label dan menggunakan label. Switch bisa berdiri sendiri tanpa perlu menambahkan ID, karena input dibungkus langsung oleh tag <label>.

Column

Ada 12 bagian dalam 1 kolom, dan semua terbagi dalam masing-masing class. Kolom wajib dibungkus dengan class .cr-row untuk mengaktifkan CSS flexbox.

  • Class kolom dimulai dari .col-1 sampai .col-12
  • Bebas mengkombinasikan semua class kolom dengan total maksimal 12 kolom per baris
  • Contoh kombinasi : .col-8 dan .col-4 atau .col-6 dan .col-6

column Breakpoint

Untuk mengatur ukuran pada layar tertentu, tambahkan md atau lg setelah tulisan .col-

  • Contoh : menggunakan class .col-12 .col-md-6 .col-lg-3 secara bersamaan akan membuat kolom menjadi full saat layar kecil dan membuat kolom menjadi 2 bagian saat layar sedang dan membuat kolom menjadi 4 bagian saat layar besar (resize layar untuk cek hasilnya).
